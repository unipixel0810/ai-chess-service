## 3. DNA 분석 (향후 UI 확장)

- **공격/수비 지표**: `DNA_Analyzer`의 `getStyleSnapshot()` → aggressive / defensive 수치
- 화면 하단 또는 사이드에 “공격적 72% / 수비적 45%” 같은 뱃지/바 형태로 표시 가능
